Лабораторная работа №4. Сохранение рисунка Canvas по таймеру

Выполнил: Козлов Олег Антонович, гр. 6231-010402D

Файлы проекта:

main.py        - backend на Python: таймер и сохранение Canvas

mainWindow.qml - frontend на QML: окно и область рисования

Circle.qml     - элемент выбора толщины линии

Square.qml     - элемент выбора цвета

Запуск:

python main.py

Описание файла main.py

В файле создан класс Interface, реализующий backend-логику приложения.
В конструкторе класса создаётся папка snapshots рядом с main.py. В эту папку автоматически сохраняются изображения
области рисования.В классе создаётся объект QTimer с интервалом 10 000 миллисекунд.После запуска таймер вызывает метод save_canvas каждые 10 секунд,
независимо от действий пользователя. Метод создаёт имя файла с текущими
датой и временем.Далее сохраняется текущее содержимое Canvas в PNG-файл.
После загрузки mainWindow.qml Python находит объект Canvas по свойству
objectName и передаёт его в класс Interface.

Описание файла mainWindow.qml

Файл содержит графический интерфейс приложения Painter. В верхней части окна
находится панель инструментов: цветные квадраты для выбора цвета линии и
круги для выбора толщины линии. Нижняя часть окна содержит область рисования
Canvas.При нажатии и перемещении мыши Canvas получает координаты курсора и рисует
линии выбранного цвета и толщины.

Описание файлов Circle.qml и Square.qml

Circle.qml содержит элемент выбора толщины линии. При нажатии на круг
выбирается соответствующая толщина кисти.

Square.qml содержит элемент выбора цвета линии. При нажатии на цветной
квадрат выбранный цвет передаётся в Canvas и используется для рисования.
