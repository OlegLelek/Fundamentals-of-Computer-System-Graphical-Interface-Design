Файлы проекта:

main.py       - главное окно приложения

picture.png   - изображение, которое отображается по нажатию кнопки

Запуск:

python main.py

Описание файла main.py

Главное окно приложения на PyQt5. Создаёт окно с надписью (QLabel) и кнопкой
(QPushButton). Изначально надпись отображает текст-приглашение нажать кнопку.
При нажатии на кнопку вызывается слот on_button_click, который заменяет
текст надписи на изображение picture.png через метод setPixmap, а надпись
на кнопке меняется на «Показать текст». При повторном нажатии надпись
возвращается к исходному текстовому виду через label.clear() и setText.
