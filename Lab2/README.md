Лабораторная работа №2. Сигналы и слоты в PyQt5

Выполнил: Козлов Олег Антонович гр. 6231-010402D

Файлы проекта:

    main.py  - главное окно
    
    cl1.py   - класс Celsius с сигналом celsiusChanged
    
    cl2.py   - класс Fahrenheit с сигналом fahrenheitChanged

Запуск:

    python main.py
    
Описание файла cl1.py

Класс с сигналом для шкалы Цельсия.
Хранит текущее значение температуры в Цельсиях и испускает сигнал
celsiusChanged при его изменении. Также содержит формулы пересчёта
Цельсия в Кельвины и обратно (Кельвин используется как "базовая"
единица для связи с другими шкалами).

Описание файла cl2.py

Класс с сигналом для шкалы Фаренгейта.
Хранит текущее значение температуры в Фаренгейтах и испускает сигнал
fahrenheitChanged при его изменении. Также содержит формулы пересчёта
Фаренгейта в Кельвины и обратно.

Описание файла main.py

Главное окно приложения. Импортирует классы cl1.Celsius и
cl2.Fahrenheit, создаёт поля ввода для трёх шкал (°C, °F, K) и
связывает сигналы этих классов со слотами интерфейса так, чтобы при
изменении одного поля автоматически пересчитывались два других.
